Telegram-бот на Python для мониторинга состояния компьютера/сервера и удаленного управления им. Бот отслеживает ресурсы системы, строит графики нагрузки, проверяет интернет и позволяет выполнять команды прямо из мессенджера.

## 🌟 Возможности

### Мониторинг системы
*   **Базовый отчет**: Загрузка CPU, RAM, Диска с красивыми полосками прогресса.
*   **Сетевые проверки**: Проверка наличия интернета и измерение задержки (Пинг).
*   **Топ процессов**: Вывод 3 программ, которые больше всего нагружают процессор и память.
*   **Графики**: Построение графиков истории загрузки CPU и RAM (библиотека `matplotlib`).
*   **Автоотчеты**: Бот присылает полный отчет каждые 5 минут (время настраивается).

### Удаленное управление (Только для Админа)
*   **Терминал**: Выполнение любых консольных команд (`/cmd <команда>`).
*   **Скриншот**: Снимок экрана рабочего стола (`/screen`).
*   **Блокировка**: Блокировка ПК (`/lock`).
*   **Питание**: Перезагрузка (`/reboot`) и выключение (`/shutdown`).

## Текстовые команды:
* **/status** — полный отчет.
* **/cmd <текст>** — выполнить команду в консоли (например, /cmd ipconfig).
* **/screen** — сделать скриншот экрана.
* **/lock** — заблокировать экран.
* **/reboot** — перезагрузить ПК.
* **/shutdown** — выключить ПК.
